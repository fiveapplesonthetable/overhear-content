## Walk-through narration (English only, no target-language words quoted)

- 'Morning has come.' The illusion is finally broken.
- 'Now everything is clear.' The reality is obvious now.
- 'But it is already late.' Time has passed while we slept.
- 'Time has gone.' We can never get it back.
- 'This is our common mistake.' We have to accept the blame.
- 'Maybe we should have woken up?' A regretful thought.
- 'Woken up sooner?' It would have saved a lot of pain.
- 'I don't know the answer.' There are no easy answers.
- 'Nobody knows.' We all struggle with the same things.
- 'Life goes on.' We have to keep moving despite everything.
- 'Need to go.' It is time to face the future.
- 'Go only forward.' The only direction left.
