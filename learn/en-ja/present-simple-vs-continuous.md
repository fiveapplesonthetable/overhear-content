# 「普段の習慣」と「今・今週の動き」：現在形と現在進行形

> 三人称単数の -s を付ける現在形（it rains）と、今起きていることや確定した予定を表す be + -ing の違い。

シーズン1・エピソード1〜2より。

英語は「いつも繰り返される習慣・性質」と「今まさに進行中のこと」をはっきり区別します。普段の習慣や一般的な事実には現在形を使い、主語が *he*・*she*・*it*（単数）のときは動詞に `-s` を付けます：*I always walk fast*、*Paper never loses the room list when it rains*、テッサは *talks to everyone*。

一方、今目の前で起きている動作や、「今日だけいつもと違うこと」「すでに決まっている今日・今週の予定」には *am* / *is* / *are* + `-ing` の現在進行形を使います：*It is raining outside*（「外は今雨が降っている」）、*today we are making French style eggs*（「今日はフランス風の卵を作っている」）、そして宿泊予定の *Room four is arriving today* や *Today's guest in room four is staying all week* です。

電話口のハンナが名乗る *speaking* や、用件を確認する *You are calling about the dark blue suitcase* も、まさに今通話しているライブ感を表しています。

## シリーズからの例文

- **Paper never loses the room list when it rains.** — _紙なら雨が降っても客室リストが消えることは決してないからね。_ (`linden-courtyard-ja-s01e01-scene-01`, seg 8)
- **Today's guest in room four is staying all week. Everything must be perfect!** — _今日の四号室のお客さまは一週間ずっと滞在される。すべて完璧でなくては！_ (`linden-courtyard-ja-s01e01-scene-03`, seg 3)
- **Hannah bought sea salt butter, so today we are making French style eggs!** — _ハンナが海塩バターを買ってきたから、今日はフランス風の卵料理を作っているのよ！_ (`linden-courtyard-ja-s01e02-scene-04`, seg 2)
